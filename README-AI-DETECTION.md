# AI Image Detection Feature

This feature allows you to detect whether an image was generated by AI using the SightEngine API. It's particularly useful for identifying deepfakes and AI-generated images.

## Setup

1. Sign up for a SightEngine account at [https://sightengine.com/](https://sightengine.com/) to get your API credentials
2. Add your SightEngine API credentials to the `.env` file:
```
SIGHTENGINE_API_USER=your_api_user
SIGHTENGINE_API_SECRET=your_api_secret
```

## Features

- Detect if an image was generated by AI tools like DALL-E, Midjourney, or Stable Diffusion
- Analyze images either by uploading files or providing URLs
- Adjust detection threshold based on your needs
- Get a confidence score indicating the likelihood of AI generation

## How It Works

The feature uses SightEngine's `genai` model, which is specifically designed to detect AI-generated images. The API returns a score between 0 and 1, where higher values indicate a greater likelihood of AI generation.

The backend endpoint can be accessed in two ways:

1. **File Upload:**
```
POST /detect-ai-image
multipart/form-data: 
  - file: [image file]
  - threshold: 0.7 (optional, default)
```

2. **URL Analysis:**
```
POST /detect-ai-image
multipart/form-data:
  - image_url: "https://example.com/image.jpg"
  - threshold: 0.7 (optional, default)
```

## Response Format

```json
{
  "success": true,
  "message": "AI detection completed successfully",
  "ai_generated_score": 0.92,
  "is_ai_generated": true,
  "media_info": {
    "id": "med_123456",
    "uri": "https://example.com/image.jpg"
  },
  "request_id": "req_123456"
}
```

## Interpretation

- **0-30%**: Likely a natural image
- **30-70%**: Uncertain, might contain AI-generated elements
- **70-100%**: Likely an AI-generated image

## Limitations

- The detection is not perfect and may have false positives or negatives
- Some advanced AI-generated images might evade detection
- Very small or low-quality images may produce less reliable results

## Frontend Integration

The feature is available through the main navigation bar and includes:
- File upload or URL input
- Preview of the image being analyzed  
- Visual presentation of the detection results
- Adjustable detection threshold
